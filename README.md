# vLLM Benchmark Helper

This repository provides a flexible and easy-to-use wrapper around the `vllm bench serve` command. The primary script to run experiments is `run_vllm_bench.py`. 

It uses a YAML configuration file to define both experiment metadata and the arguments passed to the vLLM benchmark CLI tool.

## Key Features

- **Arbitrary Flag Parsing**: The script maps arguments defined in the YAML file directly to CLI flags for `vllm bench serve`. You can add *any* valid vLLM CLI flag under the `vllm_args` section without modifying the Python script.
- **1-Dimensional Parameter Sweeps**: You can provide a list (array) of values for any argument in `vllm_args`. The script will detect the list and automatically perform a 1D sweep, launching a separate benchmark run for each value sequentially while keeping all other arguments constant. *(Note: Only one list, or multiple lists of the exact same length, can be swept at a time; no Cartesian product is performed).*
- **Dynamic CSV Metadata Inclusion**: The script generates a comprehensive CSV file from your benchmark results. Any root-level metadata you provide in the YAML file (e.g., `hardware`, `notes`, `ip`) is automatically concatenated as columns in the output CSV, ensuring all context is kept right alongside your metrics without requiring code changes.

## Usage

### 1. Create a Configuration File

Create a YAML file (e.g., `exp_1d_sweep.yaml`) defining your cluster setup, custom metadata, and standard `vllm_args`.

```yaml
# --- Experiment Metadata & Setup ---
# These fields will be exported as columns in the final CSV.
ip: "localhost"
port: 8200
short_experiment_name: "throughput_vs_isl"
hardware: "2x_a3ultra_8xh200"
notes: "Testing input sequence length scaling"
pd_enabled: "true"
max_retries: 3
gpu_cooldown_sec: 2

# --- vLLM Arguments ---
# Keys map directly to vLLM CLI flags (`num-prompts` -> `--num-prompts`).
vllm_args:
  backend: "vllm"
  model: "BCCard/Qwen3-Coder-480B-A35B-Instruct-FP8-Dynamic"
  tokenizer: "BCCard/Qwen3-Coder-480B-A35B-Instruct-FP8-Dynamic"
  endpoint: "/v1/completions"
  dataset-name: "random"
  random-output-len: 1
  num-prompts: 256
  request-rate: 3.2
  percentile-metrics: "ttft,tpot,itl,e2el"
  metric-percentiles: "90,99"
  goodput: "ttft:1000 tpot:40"
  header: "x-prefiller-host-port=10.4.1.13:8000"
  max-concurrency: 32
  save-result: true
  
  # 1D sweep: The script will run 3 times, iterating over these input lengths.
  random-input-len: [1000, 2000, 3000]
```

### 2. Run the Script

```bash
python3 run_vllm_bench.py exp_1d_sweep.yaml
```

### 3. Check the Results

Results are saved into an `experiments/` directory grouped by your `short_experiment_name`.

Inside `experiments/<short_experiment_name>/`, you will find:
- **`benchmark_results_v2.csv`**: Contains the benchmark metrics concatenated seamlessly with all the metadata you defined at the root of your YAML file. 
- **`failed_runs.json`**: Logs any configurations that failed after the maximum number of retries.
- **`raw_results/`**: Directory containing the raw `.json` output files generated by `vllm bench serve`.
